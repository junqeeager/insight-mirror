# 截图目录说明

本目录用于存放 README「Screenshots」章节使用的截图。

> 截图需在本地启动 Streamlit 后手动截取，暂不提交占位图片，避免 README 出现失效图片链接。

建议命名与内容：

| 文件名（建议） | 内容 | 状态 |
| --- | --- | --- |
| `dashboard.png` | 首页概览：总事件数、最近事件、快捷操作 | 待补充 |
| `time-view.png` | 时间视图：活跃时段热力图、事件时间线、来源/类型分布 | 待补充 |
| `graph-view.png` | 关系视图：兴趣关联网络、平台分布雷达图、标签云 | 待补充 |
| `report-view.png` | 报告视图：画像快照与完整 HTML 报告 | 待补充 |

补图后请同步更新 `README.md` 中的图片引用（建议 1600px 宽、PNG 格式）。
