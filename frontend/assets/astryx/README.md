# Astryx 主题资产

- `astryx.css`：`@astryxdesign/core@0.2.0` 的 `dist/astryx.css`
- `theme.css`：`@astryxdesign/theme-neutral@0.2.0` 的 `dist/theme.css`
- `LICENSE`：Astryx 仓库根目录 MIT License

来源与说明：

- https://github.com/facebook/astryx
- https://www.npmjs.com/package/@astryxdesign/core

变量映射到 Streamlit 原生组件的 DOM 选择器。
